# T1547.001: Boot or Logon Autostart Execution (Registry Run Keys)

**Machine cible :** PC1

## Objectif
Établir une persistance pour exécuter automatiquement un programme
au démarrage ou à la connexion de l'utilisateur.

## Action réalisée
Ajout d'une entrée dans la clé de registre
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.

## Traces générées
- Sysmon Event ID 13 (écriture dans la clé Run)

## Résultat Wazuh
Activité suspecte détectée via le décodage des clés de persistance connues.

## Niveau de détection
Bon

## Amélioration
Aucune lacune majeure relevée dans le rapport.
