# T1059.001: Command and Scripting Interpreter (PowerShell)

**Machine cible :** PC1
**Statut :** En cours

## Objectif
Évaluer la visibilité sur l'exécution d'instructions PowerShell
potentiellement malveillantes (téléchargement de script, exécution encodée).

## Action réalisée
Exécution d'une commande PowerShell suspecte sur PC1.

## Traces générées
- Sysmon Event ID 1 (création de `powershell.exe`, analyse de la ligne de commande)

## Résultat Wazuh
Remontée en cours d'ajustement.

## Niveau de détection
À optimiser

## Lacune et amélioration
Les commandes encodées/obfusquées nécessitent l'activation du
**Script Block Logging (Event ID 4104)** pour une visibilité complète,
au-delà du simple Event ID 1 de Sysmon.
