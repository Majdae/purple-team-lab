# T1021.001: Remote Services (Remote Desktop Protocol)

**Machines :** PC1 / DC1

## Objectif
Valider la détection d'accès distants non autorisés ou d'activations
suspectes du protocole RDP.

## Action réalisée
Activation du service RDP à distance ou ouverture d'une session RDP
depuis DC1 (ou une machine distante) vers PC1.

## Traces générées
- Windows Security Event ID 4624 (ouverture de session réussie, Logon Type 10)
- Event ID 7045 (installation de service)

## Résultat Wazuh
Connexion distante réussie remontée.

## Niveau de détection
Moyen (manque de règles personnalisées)

## Amélioration
Ajouter des règles Wazuh personnalisées ciblant les connexions RDP (Logon Type 10).
