# T1053.005: Scheduled Task/Job (Scheduled Task)

**Machine cible :** PC1

## Objectif
Créer une tâche planifiée pour maintenir une persistance ou exécuter
des actions différées à privilèges élevés.

## Action réalisée
Création d'une tâche nommée `WazuhLabTest` via `schtasks /create`
(exécution quotidienne).

## Traces générées
- Windows Security Event ID 4698 (A scheduled task was created)
- Sysmon Event ID 1 (Process Creation, schtasks.exe)

## Résultat Wazuh
Création de la tâche planifiée détectée.

## Niveau de détection
Bon

## Amélioration
Règle Wazuh personnalisée pour lever une alerte de sévérité accrue
lors de la création d'une tâche planifiée.
